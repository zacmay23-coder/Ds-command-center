        Secure shared-master workflow

        Enter the Realtime Database URL and Web API key from Firebase project settings. Sign in using an officer account created in Firebase Authentication. The application automatically obtains and refreshes Firebase ID tokens; passwords are never stored.

        Publish This Device uploads the complete current record. Pull Master Record downloads the shared roster, historic battles, awards, and screenshot evidence. Before overwriting, the app compares cloud revision timestamps and warns when another device has published a newer record.

        Required database rules: authorised UIDs must be listed under /officers/UID: true, and the selected master key must use officer-only read/write rules.

        The API key, email, refresh token and database details stay only in this browser. Exported battle backups do not include cloud credentials. Large screenshot archives increase Firebase database storage and transfer use.
